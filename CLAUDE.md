# Правила работы в этом проекте

## Язык

**Отвечать всегда по-русски.** Код, имена файлов, коммиты — по-английски, как сейчас.

**Коротко.** Без вступлений и повторов. Но ничего не выбрасывать: если фактов
пять, должно остаться пять — просто в двух строках вместо двадцати.

## Проект

Голосовой companion для прадеда. Полный план — `docs/BUILD-PLAN.md`,
характер — `docs/VISION.md` и `docs/SOUL.md`.

## Арт-пайплайн

Как делается графика — `docs/HOW-THE-ART-IS-MADE.md`.
Автоматизация и телефон — `docs/JARVIS-SETUP.md`.

```bash
python3 tools/generate_variants.py tree-leafy-11   # 4 варианта -> контактный лист
python3 tools/accept_variant.py tree-leafy-11 B    # выбранный -> в мир
python3 tools/inspect_assets.py                    # проверка всех плашек
```

Правила, которые нельзя нарушать:

- `assets/raw/` — оригиналы, как пришли от генератора. Не редактировать никогда.
- Имена файлов из `assets/raw/README.md` — точные. Переименованный файл =
  сломанный ассет.
- Свет всегда сверху справа. Тени рисует код, не генератор.
- В манифесте `w`/`h` — измерения, их можно перезаписывать. `sway`, `solid_m`,
  `height_m` — решения человека, их не трогать при регенерации.
